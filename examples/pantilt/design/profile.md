# Profile

C1–C3 in `discover/audiences.md` decide which audience the shape serves.

## Describe (what is it, how is it used)
| | Must | Must never |
|---|---|---|
| Buyer/user at rest | read as a phone mount on a turning head; phone clips in from the front | read as a speaker, desk light or robot |
| Buyer/user in use | show plainly which part turns and which tilts | hide the joints |
| Students (via video) | nothing; they see only the frame | — |

## Express (what qualities)
| | Must | Must never |
|---|---|---|
| Buyer/user at rest | quiet, precise, heavy-footed | playful, cute, glossy |
| Students in use | calm camera moves | jerks, hunting, audible buzz |

## Exhort (what it makes you want to do)
| | Must | Must never |
|---|---|---|
| Buyer/user | put the phone in and forget it | talk to it, look at it, pet it |
| Students | keep watching the teacher | notice the camera |

## Identify (family)
| | Must | Must never |
|---|---|---|
| Buyer/user | camera and broadcast gear | consumer robots, toys, smart speakers |
| Streamer's viewers (on camera) | pro accessory | gadget from a bargain bin |
