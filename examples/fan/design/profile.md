# Profile

| Function | Audience · state | Must | Must never |
|---|---|---|---|
| Describe (what is it, how used) | user · rest | read as a fan from its round grille; the button reads as the only control | read as a speaker or desk light so the button is hunted for |
| Describe | user · in use | show its sweep as slow and even | jerk at the ends of the sweep |
| Express (qualities) | buyer · rest | read as made with care: even walls, broken edges, one colour | show print seams on the front, a visible screw |
| Express | user · in use | sound like nothing | whine, click, hum |
| Exhort (what it makes me do) | user · rest | invite one press of one button | invite reaching for a phone or a remote |
| Exhort | influencer · on camera | invite "where is that from?" | invite "is that a gadget?" |
| Identify (family) | buyer · rest | belong with desk objects (desk lights, speakers, the shop's accessories) | belong with PC peripherals or gaming gear |
| Identify | influencer · rest | read as one small maker's object | carry a brand logo on the front |

Conflicts from `discover/audiences.md`: C1 and C2 follow the user (the shape serves quiet and calm); the buyer and influencer are served through finish, colour and packaging.
