# Semantic profile

C1 and C2 follow the user (audiences.md): the shape serves the parent.

| | Must | Must never |
|---|---|---|
| Describe (what is it, how is it used) — user at rest | read as a kitchen container with one drawer | read as a device, a robot or a medical box |
| Describe — user in use | show that the drawer is the one thing to pull | show a second opening or a control |
| Describe — buyer | read as something their parent will keep on the counter | read as a gadget to set up on the device itself |
| Describe — influencer | show that doses come one at a time | show all doses at once |
| Express (qualities) — all | calm, sturdy, warm | clinical, fragile, playful |
| Exhort (what it makes me do) — user in use | pull the drawer when it calls | press, tap or read anything |
| Exhort — user at rest | leave it alone | invite opening the lid |
| Identify (family) — all | breadbins, canisters, kitchen timers | pill organisers, hospital equipment, smart speakers |
