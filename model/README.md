# tangware

Mechanical design as code, on build123d: parts mated as in CAD and assembled. It installs the `cad` command; the build in the Tanġware studio exports the STEP, GLB and print STLs and runs the checks, simulation, stress and bill.

```sh
pip install tangware
cad new my-product --name "My product"
```

A coding agent takes a product from idea to a priced, buildable design by following the runbooks and rules in the [source repo](https://github.com/Tangware/library), which also holds worked examples.
